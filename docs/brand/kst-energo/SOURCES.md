## Метод

1. Страницы открыты в браузере, осмотрены визуально; основные значения прочитаны через `getComputedStyle`.
2. Исходные CSS, SVG и три WOFF2-шрифта сохранены из ресурсов посещённых страниц. Тексты CSS сохранены без исправлений.
3. Для desktop использовался viewport 1600 × 1000, для mobile — 390 × 844 CSS px, DPR 1. Настольная полоса прокрутки оставляла контентную ширину 1585 и 375 px соответственно. Это не точная эмуляция аппаратного телефона.
4. Мобильная главная повторно открыта после смены ширины. Это исключило сохранённое состояние карты desktop-страницы, которое при простом сужении окна превращалось в открытый нижний лист.
5. Для описания брались установившиеся значения после CSS-переходов. Начальные промежуточные значения размеров после resize не использовались как токены.
6. Проверены существующие названия экранов и типы данных «КОНТУРа». Мобильные размеры и недостающие семантические роли добавлены отдельно с маркировкой «Адаптация».

## Расхождения, которые учтены

**Несколько синих.** В логотипе и основной кнопке используется `#135AA6`, в части навигации — `#0056A4`, в стрелках — `#005B9C`. В рекомендации выбран первый цвет, поскольку он подтверждён самим логотипом. Остальные не объявлены новыми обязательными брендовыми ролями.

**Поля формы.** В `source/style.css:2617` перед `{` у общего списка селекторов стоит лишняя запятая. Браузер отбрасывает правило. В осмотренной форме поля реально имеют белую подложку, радиус 4 px, контур `#CED4DA`, padding 6 × 12 px; input высотой 70 px, textarea 38 px. Поле прикрепления документа при этом имеет радиус 20 и подложку `#F0F0F3`. Это подтверждено снимком формы и измерением `automation-visible-fields-1600`. Исходный сайт не изменялся; мобильное поле описано как отдельное предложение.

**Контраст hover.** Яркое состояние `#1787FF` даёт с белым текстом 3,53:1. В мобильных токенах нажатие затемняет синий. Светлый текст `#B2B9C1` также не перенесён в существенные подписи.

**Поведение и идентичность.** Карусели, длинные корпоративные меню, большие рекламные поля, `user-select: none`, `outline: none` и циклическая анимация не являются обязательными признаками бренда. Для приложения используются его реальные задачи и платформенные способы взаимодействия.

## Ресурсы и лицензии

SVG, изображения и CSS КСТ сохранены как материалы данного исследования. Их источники перечислены в `asset-manifest.json`. Сохранение файла не устанавливает отдельного разрешения на публикацию или изменение товарного знака. Официальный корпоративный брендбук на обследованных страницах не найден.

- **Geologica:** WOFF2 400/500/600 получены с сайта КСТ. [OFL.txt](assets/fonts/OFL.txt) взят из [репозитория Google Fonts](https://github.com/google/fonts/blob/main/ofl/geologica/OFL.txt); copyright — The Geologisk Project Authors.
- **IBM Plex Mono:** WOFF2 из уже установленного пакета проекта `@fontsource/ibm-plex-mono`; [лицензия](assets/fonts/IBM-Plex-Mono-OFL.txt) сохранена рядом. Это шрифт данных «КОНТУРа», а не найденный шрифт сайта КСТ.
- **Фоновое видео:** наличие отмечено при просмотре; видеофайлы в комплект не включались. Для мини-брендбука достаточно статического узора.
- **Фотографии доказательств осмотра:** в мини-брендбук не добавлялись; числовой пример мобильного экрана подписан как условный.

## Проверка комплекта

Из корня проекта:

```powershell
python "docs/brand/kst-energo/tools/verify_design.py"
```

Проверка разбирает YAML и JSON, сопоставляет общие цвета, проверяет токенные ссылки, локальные ссылки Markdown/HTML, размеры и заголовки изображений/шрифтов, SHA-256 ресурсов и контраст заданных рабочих пар. Результат записывается в `verification.json`.

Для браузерного просмотра на этом компьютере, из корня проекта:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Открыть [локальный мини-брендбук](http://127.0.0.1:8765/docs/brand/kst-energo/brandbook.html). Такой адрес работает на этом компьютере; это не размещение приложения в интернете.

Визуальная проверка HTML проводится в широком и узком viewport. Проверки комплекта не заменяют тестирование будущего мобильного приложения на устройстве и не подтверждают внедрение предложенной темы.
