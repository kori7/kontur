# Уставки описания рядов против колонки «Диагноз»

Сформировано 14.11.2026 скриптом `scripts/qa/series-agreement.py` из `services/api/app/series_check.py`.

Организатор разрешил считать колонку «Диагноз» эталоном для проверки логики (ответы §6). К каждой часовой записи применены ровно те уставки, которые написаны в описаниях рядов (`vibration-002`, `temperature-002`): «выше» читается как строго больше, при нескольких превышениях берётся более серьёзный уровень. Ничего не подбиралось под разметку.

## Что это значит и чего не значит

- Ни одна запись с отклонением по разметке не отнесена к норме: для заказчика пропуск хуже ложной тревоги (ответы §5).
- Это проверка согласованности логики с разметкой организатора на его же сгенерированных данных, а не точность диагностики реального насоса.
- Ряды прикреплены к основному агрегату Wilo решением команды, которое разрешил заказчик; принадлежность рядов агрегату не доказана.
